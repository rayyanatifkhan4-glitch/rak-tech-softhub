# RAKTechSoftHub | Digital & Physical Infrastructure Foundry

Official repository for **RAKTechSoftHub** — High-Performance Software, Physical Networking, Server Architecture, and Creative Technology.

---

## 📁 Repository Structure

* **`Website/`**: Live production static website (HTML5, TailwindCSS, GSAP, Video motion, WebGL). Ready for deployment to Netlify and Firebase Hosting.
* **`Website_Data/`**: Archived master media, technical specifications, branding assets, and structured CMS JSON data.
* **`App/`**: Enterprise ERP & Management Software (React, Vite, Electron, TailwindCSS).

---

## 🚀 Running the Website Locally

You can launch the local static server in one click:

```bash
# Option 1: Double click run_website.bat (Windows)
# Option 2: Run via Node.js
node serve_website.js
```

Server URL: **http://localhost:3000**  
Admin Portal: **http://localhost:3000/login/admin/**

---

## 🌐 Netlify Deployment

The repository includes `netlify.toml` configured to automatically publish the `Website` directory on push to `main`.
